# goit-advancedjs-hw-05

Тема 9. Вступ до TypeScript. Домашня робота.

## Критерії приймання

- Створено репозиторій `goit-advancedjs-hw-05`.
- Домашня робота містить посилання на робочу сторінку на `GitHub Pages`.
- До роботи прикріплено файл репозиторію у форматі `zip`.
- Коректно налаштоване середовище розробки.
- Коректно налаштований компілятор.
- Встановлено source maps в `tsconfig.json` у проєкті TypeScript.

## GitHub Pages

https://alandrius.github.io/goit-advancedjs-hw-05/

## Запуск локально

```bash
npm install
npx tsc
npm start
```

Для автоматичної компіляції під час змін:

```bash
npx tsc -w
```
